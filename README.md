# Интернет-магазин

Учебный проект: HTML + CSS + JavaScript, Node.js + Express, MySQL.

## Возможности
- каталог с поиском, фильтром по категории, сортировкой и страницами
- корзина и оформление заказа (транзакция)
- регистрация и вход (пароли хранятся в виде хешей, токен JWT)
- админка для управления товарами

## Запуск
1. Выполните SQL-скрипты из папки sql (или восстановите shop_db_backup.sql)
2. Скопируйте server/.env.example в server/.env и укажите свои значения
3. В папке server: npm install, затем npm start
4. Откройте index.html в браузере
